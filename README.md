# Dev Notes

This repository is a collection of my personal development notes, written in a way that makes sense to me. I'm curious by nature, and I've always needed to understand the **why** behind something before I can fully understand the **how**. Simply knowing that something works isn't enough. I want to understand what it does, why it works, and how everything connects.

I like breaking concepts down into smaller, more manageable pieces, sometimes going into more detail than most documentation would. My goal is to keep things organized, practical, and easy to follow, with explanations and examples that I can revisit months or even years later without having to relearn everything from scratch.

For years, I've kept my notes in Microsoft OneNote. Over time, they've grown into a collection of things I've learned, researched, and wanted to remember. I eventually realized it would be better to organize everything into Markdown files and share them through GitHub. Transcribing all those notes will take some time, but I'll continue adding to this repository as I go. Slowly but surely.

While these notes are primarily for my own learning and reference, I hope they'll help others along the way. If an explanation here helps someone understand something they've been struggling with, that alone makes sharing them worthwhile.
