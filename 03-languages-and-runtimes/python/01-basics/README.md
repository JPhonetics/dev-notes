# Python Basics

Python Basics introduces the foundational concepts of Python programming, focusing on understanding how the language works rather than simply memorizing syntax.

Each guide builds on the concepts introduced in earlier sections, using explanations and practical examples to demonstrate how Python code behaves and why it produces certain results.

By the end of Python Basics, you should be comfortable reading, writing, and troubleshooting simple Python programs independently. More importantly, you should understand how the concepts work together and have the foundation needed to explore more advanced topics.

## Overview

1. **[Write and Execute Python Code](01-writing-and-executing.md)** — Create a Python file, execute a script, and view its output.
2. **[Syntax and Structure](02-syntax-and-structure.md)** — Learn identifiers, naming conventions, keywords, statements, expressions, indentation, line continuation, comments, and docstrings.
3. **[Variables](03-variables.md)** — Assign and reassign values, use constants, and work with multiple assignment and unpacking.
4. **[Data Types](04-data-types.md)** — Understand Python's built-in types, dynamic typing, type checking, and basic conversions.
5. **[Operators](05-operators.md)** — Use arithmetic, comparison, logical, assignment, membership, and identity operators.
6. **[Numbers](06-numbers.md)** — Work with integers, floating-point numbers, complex numbers, and numeric precision.
7. **[Strings](07-strings.md)** — Create, access, format, and manipulate text.
8. **[Booleans and None](08-booleans-and-none.md)** — Understand truth values, truthiness, and the meaning of `None`.
9. **[Collections](09-collections.md)** — Store and access groups of values using lists, tuples, ranges, dictionaries, sets, and related types.
10. **[Objects and Mutability](10-objects-and-mutability.md)** — Explore object identity, references, mutable and immutable values, and copying.
11. **[Conditionals](11-conditionals.md)** — Make decisions using `if`, `elif`, and `else`.
12. **[Loops](12-loops.md)** — Repeat operations using `for` and `while`, including loop-control statements.
13. **[Functions](13-functions.md)** — Define reusable functions, use parameters and arguments, and return results.
14. **[Input and Output](14-input-and-output.md)** — Receive user input and display or format program output.
15. **[Exception Handling](15-exception-handling.md)** — Recognize exceptions and handle errors with `try`, `except`, `else`, and `finally`.
16. **[Modules and Imports](16-modules-and-imports.md)** — Organize code into modules and access functionality using imports.
17. **[File Handling](17-file-handling.md)** — Open, read, write, and safely close files.
18. **[Comprehensions](18-comprehensions.md)** — Create collections using concise comprehension syntax.
19. **[Best Practices](19-best-practices.md)** — Apply naming conventions, readability principles, documentation habits, and other maintainability practices.

## Official Documentation

The following resources are maintained by the Python project and are useful when you need a more detailed or authoritative explanation:

- [The Python Tutorial](https://docs.python.org/3/tutorial/) — Official introduction to Python's language features and common programming concepts.
- [The Python Language Reference](https://docs.python.org/3/reference/) — Detailed reference for Python syntax and language behavior.
- [The Python Standard Library](https://docs.python.org/3/library/) — Documentation for built-in types, functions, modules, and other standard functionality.
- [Python Built-in Functions](https://docs.python.org/3/library/functions.html) — Reference for functions such as `print()`, `type()`, `len()`, and `input()`.
- [Python Glossary](https://docs.python.org/3/glossary.html) — Definitions of Python terminology.
- [PEP 8 — Style Guide for Python Code](https://peps.python.org/pep-0008/) — Conventions for formatting and writing readable Python code.
- [PEP 257 — Docstring Conventions](https://peps.python.org/pep-0257/) — Guidance for writing documentation strings.
